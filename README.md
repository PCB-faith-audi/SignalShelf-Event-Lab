# SignalShelf Event Lab

A small Node.js and Express prototype built as part of The Meridian Pivot.

## Purpose

This project was created to independently learn an unfamiliar backend concept: event-driven communication using HTTP webhooks.

## Concepts Learned

- Node.js
- Express
- GET and POST requests
- JSON request bodies
- Webhook-style endpoints
- Input validation
- HTTP status codes
- Redis-backed asynchronous queue using BullMQ
- Dynamic route parameters
- Basic REST-style API design

## Endpoints

- `GET /`
- `POST /webhooks/resource-update`
- `GET /resources/:id`
